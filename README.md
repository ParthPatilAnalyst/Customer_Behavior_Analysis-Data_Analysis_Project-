# Customer_Behavior_Analysis-Data_Analysis_Project-
I worked on a project to understand how customers shop using a dataset of 3,900 transactions. The goal was to find patterns in spending, product choice, and customer segments. The data had missing values and mixed formats, so I cleaned it using Python by fixing null ratings, renaming columns, and creating new fields like age groups and purchase frequency. I then loaded the cleaned data into PostgreSQL and wrote SQL queries to find insights such as top products, revenue by age, discount usage, subscriber behavior, and shipping type impact. After that, I built an interactive Power BI dashboard to show all insights clearly. This helped the business improve targeting, boost subscriptions, and plan better marketing.

Tools: Python, Pandas, NumPy, PostgreSQL, SQL, Power BI.
